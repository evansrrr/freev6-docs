## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 11 x64 |
| 网络 | 连通公网 IPv6 |
| 磁盘空间 | ~ 100 MB |
| 端口 | `13335` |
| 代理 | 无代理运行 |

## 校验下载的文件

下载完成后可在 PowerShell 中计算比对安装包的 SHA256：

```powershell
Get-FileHash .\FreeV6_0.4.5_x64-setup.exe -Algorithm SHA256
```
