# 常见问题

## 我的校园网可以实现免流吗？

符合校园网的条件，见 [FreeV6 介绍](/guide/introduction)

## 使用免流网络延迟高 / 速度较慢

任何免流方式都是**功能大于体验**，鱼和熊掌不可兼得。试着重新测一下延迟并选择响应较快的接入点。

免流软件不是加速器，玩游戏会有较高延迟和丢包。

## 启动免流失败

按顺序排查：

1. 确认已下载运行核心：打开 `设置 → 核心状态`，未下载可遵循引导完成下载安装
2. 确认本机 IPv6 正常：访问 [testipv6](https://testipv6.cn) 检测，并退出其他代理工具
3. 必要时点击 `设置 → 注册接入凭据` 的“**重新注册**”重试
4. 原则上免流功能只对第二代中国教育和科研计算机网用户提供，请连接校园网使用

## 启动免流后，某些网站和软件打不开（如校内资源）

在 `设置 → 绕过校园网/白名单` 中添加校内网段或白名单域名，然后**重新启动免流**

例：校园网登录页 IP 为 `202.204.48.82`，可添加 `202.204.0.0/16`，免流时即可访问此页面

## 软件没有响应 / 无法启动

本地接口固定在端口 `13335`，若被其它软件或系统进程占用会导致启动失败，关闭占用该端口的程序后重试

## 支持哪些平台？

目前仅支持 **Windows 11 x64**，其他平台暂无适配计划

## 如何更新到新版本？

启动 FreeV6 时会自动检查一次更新，若发现新版本会有提示，可一键下载安装。新版本发布在 [Releases](https://github.com/evansrrr/free-v6/releases) 页面，也可以手动下载新的安装包覆盖安装；`关于 → 软件版本` 可查看当前版本号，每个版本的改动见[更新日志](/about/changelog)

## 使用免流会被封号吗？有风险吗？

请在遵守校园网及相关网络工具使用条款和规定的前提下使用，使用产生的一切后果由用户自行承担，详见[用户协议与免责声明](/about/agreement)

## 能同时使用其他代理吗？

设置页提供链式代理，支持导入 yaml 格式订阅，但不保证兼容所有协议。暂不能和其他代理软件同时使用。

## 还是解决不了？

提交 [Issue](https://github.com/evansrrr/free-v6/issues)，尽量附上：

- 你的操作步骤与预期结果
- `日志` 页面的相关输出
- FreeV6 版本与其他可能有帮助的信息

详尽的运行环境说明有助于解决问题，但注意不要附带完整 IP 地址
