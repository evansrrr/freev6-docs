# 常见问题

## 我的校园网可以实现免流吗？

已接入教育网 IPv4 的单位，可按 IPv4 带宽 1:1 免费获得 IPv6 带宽。但**各高校校园网计费策略不同，务必确认你所在高校的校园网可提供有效 IPv6 地址，并支持 IPv6 流量免计费**。免流原理总结可参考 [ich.cc.cd 的分析](https://ich.cc.cd/2026/05/11/mianliu/)。

## 启动免流失败

按顺序排查：

1. 确认已下载运行核心：打开 `设置 → 核心状态`，未下载可遵循引导完成下载安装；
2. 确认本机 IPv6 正常：访问 [testipv6](https://www.testipv6.cn/) 检测，并退出其他代理工具；
3. 必要时点击 `设置 → 注册接入凭据` 的“**重新注册**”重试；
4. 原则上免流功能只对第二代中国教育和科研计算机网用户提供，请连接校园网使用。

## 启动免流后，某些网站和软件打不开（如校内资源）

在 `设置 → 绕过校园网/白名单` 中添加校内网段或白名单域名，然后**重新启动免流**。

例：校园网登录页 IP 为 `202.204.48.82`，可添加 `202.204.0.0/16`，实现在免流时访问此页面。

## 软件没有响应 / 无法启动

本地接口固定在端口 `13335`，若被其它软件或系统进程占用会导致启动失败。关闭占用该端口的程序后重试。

## 安装包下载很慢或打不开 GitHub

把 GitHub 链接前面加上 `https://gh-proxy.com/` 即可加速，详见[下载](/download)。客户端内置的核心下载与更新检测同样走这条加速通道。

## 支持哪些平台？

目前仅支持 **Windows 11 x64**。其他平台暂无适配计划，欢迎在 [Issues](https://github.com/evansrrr/free-v6/issues) 中反馈需求。

## 如何更新到新版本？

新版本发布在 [Releases](https://github.com/evansrrr/free-v6/releases) 页面，下载新的安装包覆盖安装即可；`关于 → 软件版本` 可查看当前版本号。每个版本的改动见[更新日志](/about/changelog)。

## 使用免流会被封号吗？有风险吗？

任何免流方式都是**功能大于体验**。请在遵守校园网及相关网络工具使用条款和规定的前提下使用，使用产生的一切后果由用户自行承担，详见[用户协议与免责声明](/about/agreement)。

## 还是解决不了？

提交 [Issue](https://github.com/evansrrr/free-v6/issues)，尽量附上：

- 你的操作步骤与预期结果；
- `日志` 页面的相关输出；
- 系统版本与 FreeV6 版本（`关于 → 软件版本`）。
