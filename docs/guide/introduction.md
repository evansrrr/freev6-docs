# FreeV6 介绍

FreeV6 是**教育网通用 IPv6 免流客户端** —— 一个免费、开源的 Windows 桌面应用。它把经过校园网的流量转发到 IPv6 通道上，让符合计费减免条件的 IPv6 流量通过校园网计费系统，从而实现免流。

当前支持的平台：**Windows 11 x64**

## 我的校园网可以用吗？

免流有效的条件如下：

1. 所在高校的校园网**提供有效的 IPv6 地址**
2. 校园网的计费策略对 **IPv6 流量免计费**
3. 连接**第二代中国教育和科研计算机网**（简称教育网）

请按照以下方法检查：

1. 打开浏览器，访问 IPv6 检测网站，例如 [ippure](https://ippure.com)、[testv6](https://testipv6.cn/)
2. 若具有 2001:da8: 开头的 IP 地址，则证明已成功拿到教育网的公网 IPv6，理论上可以使用免流

按照赛尔网络规定，已接入教育网 IPv4 的单位，可按 IPv4 带宽 1:1 免费获得 IPv6 带宽，但这并不意味着高校必须为学生提供免费 IPv6 流量，以各个高校政策为准。免流原理的详细分析见 [Raziore Blog](https://ich.cc.cd/2026/05/11/mianliu/)。

::: warning 提示
原则上 FreeV6 的免流功能只对教育网用户提供，请在遵守校园网及相关规定的前提下使用。任何免流方式都是**功能大于体验**。
:::

## 打开网卡 IPv6

Win+R 输入 **ncpa.cpl** 回车打开控制面板网络连接，右键上网网卡，打开 **属性**，确保 **ipv6 协议** 前的方框处于勾选状态，点击确定。

或者问问你豆姐

## 工作原理

1. **运行核心**——客户端需要运行核心来路由流量和请求，首次启动将引导下载（约 21 MB）并自动安装
2. **接入凭据**——客户端会自动完成接入注册，凭据只保存在电脑本地（详见[隐私政策](/about/privacy)）
3. **转发流量**——应用流量经隧道从 IPv6 通道转发出去，不再走校园网的 IPv4 路径
4. **本地可控**——“设置”中可调整路由规则和工作模式等，核心控制不需要联网

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 启停状态指示 | 仪表盘显示免流状态 |
| 接入点测速 | 测试接入点延迟，切换线路 |
| 绕过校园网/白名单 | 按网段与域名设置排除项，免流时照常访问校内资源 |
| 链式代理 | 将自有代理作为出口 |
| 共享移动热点 | 把免流网络共享给连接 Windows 热点的设备 |
| 工作模式 | 规则 / 全局 / 直连三种模式可手动切换 |
| 流量统计 | 实时上传下载、本月与累计流量明细 |
| 个性化外观 | 深色、浅色、跟随系统，支持动态取色与纯黑背景 |
| 快捷键与自启 | `F6` 唤起主窗口，支持开机自启、静默启动、自动运行免流 |
