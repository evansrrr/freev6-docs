# FreeV6 是什么

FreeV6 是**教育网通用 IPv6 免流客户端**——一个免费、开源的 Windows 桌面应用。它把你的校园网流量转发到不计费的 IPv6 通道上，让符合计费减免条件的 IPv6 流量替你“买单”。

当前支持的平台：**Windows 11 x64**。

## 我的校园网可以用吗？

先确认三件事，缺一不可：

1. 你所在高校的校园网**提供有效的 IPv6 地址**；
2. 该校的计费策略对 **IPv6 流量免计费**（各高校策略不同，务必自行确认）；
3. 你连接的是**第二代中国教育和科研计算机网**（教育网）环境。

已接入教育网 IPv4 的单位，可按 IPv4 带宽 1:1 免费获得 IPv6 带宽。免流原理的详细分析见 [实现原理](https://ich.cc.cd/2026/05/11/mianliu/)。

::: warning 使用前提
原则上 FreeV6 的免流功能只对教育网用户提供，请连接校园网使用。任何免流方式都是**功能大于体验**，请在遵守校园网及相关规定的前提下使用。
:::

## 它是怎么工作的

启动免流后，FreeV6 会在后台完成一条隧道：

1. **下载运行核心**——首次启动按引导下载 mihomo 运行核心（约 21 MB），自动完成安装；
2. **注册接入凭据**——客户端在本地完成接入注册，凭据只保存在你的电脑上（详见[隐私政策](/about/privacy)）；
3. **转发流量**——应用流量经隧道从 IPv6 通道转发出去，不再走校园网的 IPv4 计费路径；
4. **本地可控**——本地接口固定在端口 `13335`，白名单、工作模式都在“设置”里随时调整。

完整原理与设计细节见博文：[免流实现原理](https://ich.cc.cd/2026/05/11/mianliu/)。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 启停状态指示 | 仪表盘直观显示未连接、启动中、免流中状态 |
| 接入点测速 | 启动免流后测试全部接入点延迟，切换低延迟节点 |
| 绕过校园网白名单 | 按网段（CIDR）与域名设置排除项，免流时照常访问校内资源 |
| 共享移动热点 | 把免流共享给连接 Windows 热点的设备 |
| 工作模式 | 规则 / 全局 / 直连三种模式随场景切换 |
| 流量统计 | 实时上传下载、本月与累计流量明细 |
| 个性化外观 | 深色、浅色、跟随系统，支持动态取色与纯黑背景 |
| 快捷键与自启 | `F6` 唤起主窗口，支持开机自启、静默启动、自动运行免流 |

## 限制

- 仅支持 Windows 11 x64；
- 安装包未签名，下载或首次运行可能被系统拦截（选择“仍要继续”即可，见[下载与安装](/guide/install)）；
- 免流依赖校园网 IPv6 计费策略，离开校园网环境即无效。
