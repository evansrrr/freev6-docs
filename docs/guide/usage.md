# 使用说明

FreeV6 的界面分为四个页面：**仪表盘**、**接入点**、**设置**和**日志**。连接校园网后，按下面的顺序即可开始使用。

## 仪表盘

仪表盘是启动和监控免流的地方：

- **状态栏**：显示当前状态——未连接、启动中、免流中；
- **启动免流**：点击右下角按钮开始。首次使用会先引导下载运行核心，之后再次点击即可连接；运行中按钮显示“启动中…”，结束后恢复；
- **实时流量**：当前上传、下载速率；
- **流量统计**：本月与累计的上传、下载和合计，点击卡片可查看明细。

::: warning 建议手动关闭免流
退出软件或开关机时会尽量恢复网络状态，但仍建议**手动关闭免流**，避免下次开机后校园网认证异常。
:::

## 接入点

1. 先启动免流——未启动时接入点页只显示“启动免流模式以加载接入点列表”；
2. 点击“**测试延迟**”按钮，页面会显示“测试中 x/y”，逐个测试全部节点；
3. 测试完成后，选择延迟较低的接入点点击切换；
4. 停止免流后接入点列表会清空，重新启动时再次加载。

## 设置

### 外观

- **主题**：深色、浅色、跟随系统；
- **动态取色**：随系统取色生成主题色；
- **纯黑背景**：深色模式下使用纯黑背景，省电更护眼。

### 通用

| 选项 | 说明 |
| --- | --- |
| 开机自启动 | 开机后自动运行 FreeV6 |
| 静默启动 | 启动时不弹出主窗口 |
| 自动运行免流 | 应用打开时自动尝试启动免流 |
| 快捷键 | 按 `F6` 打开主窗口（需要软件在后台运行） |
| 共享移动热点 | 向连接 Windows 热点的设备共享免流 |

### 核心

- **工作模式**：
  - **规则**——按内置规则决定流量走向，日常使用推荐；
  - **全局**——全部流量经隧道转发；
  - **直连**——不经过隧道，排查问题时使用。
- **绕过校园网/白名单**：添加免流时排除的网段和域名。例如校园网登录页 IP 为 `202.204.48.82`，添加 `202.204.0.0/16` 后，免流期间也能正常打开登录页。**修改后需重新启动免流生效。**
- **链式代理**：导入 yaml 格式订阅，实现“免流套代理”，访问国外网站出口为订阅代理
- **核心状态**：确认运行核心是否已下载安装；
- **注册接入凭据**：连接异常时可点击“重新注册”重试；
- **开发者模式**：面向开发调试，日常使用无需开启。

### 关于

查看软件版本、开源许可证，一键跳转 GitHub 仓库或提交反馈。

## 日志

左侧栏底部的“日志”按钮展示运行日志。排查问题或提交 [issue](https://github.com/evansrrr/free-v6/issues) 时，附上相关日志能更快定位原因。

## 退出与恢复

- 正常退出前先**停止免流**，再关闭软件；
- 退出软件或开关机会尽量恢复网络状态，但手动关闭仍是更稳妥的做法；
- 免流状态下如遇校园网认证异常，停止免流并重新认证即可。
